# Support

## Getting Help

- Usage questions: open a GitHub Discussion (if enabled) or issue with `question` in the title.
- Bug reports: use the bug issue template and include reproduction steps.
- Security concerns: follow the private reporting process in SECURITY.md.

## What To Include

- Auditrace version
- Python version
- Storage backend in use
- Relevant command or code snippet
- Sanitized logs/error output

## SLA Expectations

Auditrace is community-maintained. Maintainer response times vary by availability.

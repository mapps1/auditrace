# S3 Storage

S3 backend stores each event as an object under a configured prefix.

Install:

```bash
pip install "auditrace[s3]"
```

Configure:

```toml
[storage]
backend = "s3"
s3_bucket = "auditrace-events"
s3_prefix = "events"
```

Works with AWS S3 and compatible APIs (MinIO, R2) if credentials are configured in your environment.
